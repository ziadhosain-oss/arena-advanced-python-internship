# 🏫 Django Fee Management System

A comprehensive fee management system for educational institutions. Manage student fees, track payments, handle multiple fee types, and generate reports - all in one place.

## ✨ Features

### Core Features
- **Student Management** - Add, edit, and delete student records
- **Fee Management** - Create and manage different fee types
- **Payment Tracking** - Record and track student payments
- **Overdue Monitoring** - Automatic overdue fee detection
- **Reports & Analytics** - Generate fee reports and summaries

### Fee Types Supported
- 💰 **Tuition Fee** - Regular academic fees
- 📝 **Exam Fee** - Examination related fees
- 📚 **Library Fee** - Library membership and services
- 🎯 **Other Fees** - Miscellaneous fees

### Key Attributes per Fee Record
- 💵 Amount Due
- 💳 Amount Paid
- 📊 Status (Paid/Not Paid/Partial/Overdue)
- 📅 Due Date
- 💰 Balance/Due Amount
