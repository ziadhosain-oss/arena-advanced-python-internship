# 🏫 Student Management System

A comprehensive web-based student management system that allows you to manage students, classes, and sections with an intuitive interface. The system includes a special feature to view students filtered by class and section.

## ✨ Features

### Core Features
- **Student Management**
  - Add new students with roll number, name, email, and phone
  - Edit existing student information
  - Delete students from the system
  - View all students in a tabular format

- **Class Management**
  - Create new classes (e.g., Class 1, Class 2, etc.)
  - Delete classes (automatically handles related sections and students)
  - View all classes with their sections and student counts

- **Section Management**
  - Create sections for specific classes (e.g., A, B, C)
  - Delete sections
  - View section-wise student distribution

### ⭐ Main Feature: View Students by Class & Section
- Filter students by selecting Class and Section
- Dynamic section loading based on selected class
- Display student list with roll number, name, email, phone
- Show total student count for the selected class-section
- Quick edit/delete actions for students
